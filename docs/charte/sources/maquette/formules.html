Comment choisir ?

La différence n'est pas dans le plan, mais dans le suivi.

Dans les deux formules, la planification de ton entraînement est réalisée avec le même niveau d'exigence et de personnalisation. La différence se situe dans le niveau de suivi et la disponibilité du coach.

Tu hésites encore ? Le bilan, inclus dans chaque formule, permet justement d'identifier ce dont tu as besoin.

Je réserve mon bilan 90 €, offert si tu poursuis avec une formule. Sans engagement. Je préfère un appel gratuit d'abord
